## v5.4.5

- 使用 GitHub Actions 内置令牌创建 GitHub Release，修复发布时的凭据错误。
- 推送版本标签会同时触发 npm 和 Docker 发布，npm 仍需通过环境审批。

### English

- Use the built-in GitHub Actions token to create GitHub releases and fix the credential error.
- Pushing a version tag triggers both npm and Docker publishing. npm publishing still requires environment approval.
