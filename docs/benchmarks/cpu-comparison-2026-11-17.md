# CPU 性能对比：普通、Fast 与 LinguaSpark

> 已更新：参见 [2026-11-23 复测（v5.4.6）](cpu-comparison-2026-11-23.md)；本文保留 v5.4.3 历史记录。

2026-11-17 实测（替代 [2026-11-16 复测（v5.4.2）](cpu-comparison-2026-11-16.md)，历史基线见 [2026-11-14（v5.1.3）](cpu-comparison-2026-11-14.md)）。普通模式（`--no-fast`）现已接入原生 SSRU 解码与 `FullVocabQ4` 全词表两阶段投影（Q4 粗排 Top-9 + FP32 精确重排），同时共享句级张量包装复用、双线性激活量化合并及零 `ort.Tensor` N-API 热路径。Fast 继续保持全部延迟与吞吐指标最优；普通模式在不使用候选词表的前提下，短句、段落与长文单请求延迟已超越或持平 LinguaSpark，并发吞吐较 5.4.2 提升 56%–81%。LinguaSpark 仍保持更低的内存占用与更短的冷启动就绪时间。本轮 27 条基准语料的三方译文与 2026-11-16 完全一致（0 差异），Fast 相比普通模式仍可能增加误译。

结构化数据见 [cpu-comparison-2026-11-17.json](cpu-comparison-2026-11-17.json)。

## 测试条件

- Ryzen 9 9950X，共享 Linux 主机；三方逐个运行，均限制 4 CPU 配额、3 GiB 内存、不使用交换空间，低调度优先级（与 2026-11-14、2026-11-16 完全一致）。
- 使用相同 Mozilla 英中、中英模型和语料；关闭翻译缓存，经预转换与预热后轮换顺序测试三轮，共 5193 次正式 CPU HTTP 请求，重复译文一致性检查及跨版本译文核对全部通过。
- MTranServer 5.4.3（提交 `5dda16e`），ONNX Runtime 1.30.0，容器启用 `tcmalloc`；普通模式与 Fast 均使用 `native-ssru`（单算子线程，4 并发槽位；普通模式使用全词表 `FullVocabQ4`，Fast 使用候选表 `ShortlistTable`）；LinguaSpark server 固定版本 `edd16a674b1484490a4a29d588dab9c1a191e6c3`，引擎固定版本 `269605c`，4 个 worker。
- 数值为三轮各自指标的中位数；延迟取每轮平均值，P95 取每轮最近秩百分位数。长文英译中 3244 字符，中译英 1516 字符，均为 32 句换行分隔。
- CPU 配额已逐例核对；rootless 环境未委派 cpuset，不能将配额理解为独占四个物理核心。本记录仅包含 CPU 数据。

普通模式接入原生 SSRU 并跳过冗余的多线程 CPU 扫描后，热模型缓存启动至就绪耗时由 5.4.2 的 4377.4 ms 降至 **1280.2 ms**（减少 70.8%）。若目录内仅有原始 Mozilla 模型文件、尚未生成 ONNX 缓存，首次离线转换耗时另计（本次预转换阶段实测：普通模式首请求英→中 2304.5 ms、中→英 2748.3 ms；Fast 首请求英→中 2227.3 ms、中→英 2483.0 ms）。内存取服务进程 RSS，不等于整个容器或系统的总占用。

## 结论与范围

- 对照组复现性：LinguaSpark 在本轮的短句 8 并发吞吐（1183.06 / 1376.36 req/s）、长文 4 并发吞吐（8.33 / 11.94 req/s）及 RSS（313.2 MiB）与前两轮基线高度吻合，宿主环境稳定。
- 普通模式对比 LinguaSpark：英→中短句单请求（2.89 ms vs 3.75 ms）、英→中与中→英段落单请求（10.63 / 13.86 ms vs 16.98 / 16.38 ms）均快于 LinguaSpark，32 句长文单请求快约 **2.35–6.13 倍**；英→中短句 8 并发吞吐（1147.73 req/s，P95 7.75 ms）与中→英长文 4 并发吞吐（11.30 req/s）已逼近启用候选表的 LinguaSpark，英→中长文 4 并发吞吐为 LinguaSpark 的 **2.80 倍**。
- Fast 对比 LinguaSpark：短句单请求延迟低约 37%–40%，短句 8 并发吞吐高约 **65%–66%**（中→英达 **2280.10 req/s**，P95 低约 34%–38%）；32 句长文单请求快约 **6.23–10.30 倍**，4 并发吞吐高约 **2.60–4.86 倍**。LinguaSpark 的常驻与峰值内存仍约为 MTranServer 的一半。

以上是共享主机受限资源下的中英双向测试，未测整机满载、其它语言或长期稳定性。各引擎重复输出一致不代表三方译文相同，也不代表翻译质量等价。
