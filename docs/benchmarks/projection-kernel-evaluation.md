# 投影内核优化工作记录

## 决策

暂不采用为 MTranServer 默认实现，也不增加按语言方向切换内核的配置。保留为研究原型：有单请求收益，但并发收益不稳定，生产接入成本尚未被收益覆盖。

## 实验范围与机制

- 基线源码：`4cd6dea`；ORT 1.30.0，Linux x86-64，Intel i5-14400，Node v26.13.1。最终整句对照固定 CPU 4、6、8、10（四个物理 P 核）。
- 普通模式全词表 INT4 投影：隐藏维度 384，英中词表 32,000、中英词表 64,000，量化块 64。
- 真实 PC 采样中，独立投影约 99% 的样本命中 INT4 点积循环；实际热路径仍采用 AVX2 的 sign/madd/hadd 指令链。不是凭 CPU 支持 VNNI 推断现有内核已使用 VNNI。
- 原型采用 unsigned INT4 × signed INT8 的 VNNI 点积，再在整数域扣除零点修正，保留逐块 scale、FMA 和最终浮点归约顺序，权重仍为 INT4。
- 最终对照仅在独立运行库副本的实验进程内替换经指纹核对的内核分派指针，保留 ORT 原有量化、预打包及线程调度。未修改安装库、模型发布制品或生产代码。

## 已验证证据

- 39 条真实输入提取 1,146 个解码向量；加采样输出前后逐 token 一致。
- 全部真实向量共 54,368,000 个 logits 逐位一致；另有 284 个边界向量通过对照。
- 4,100 列尾块与异常量化回退，在单/双线程、同 session 四路并发下通过 480 次逐位对照。
- 最终整句计时包含 4,992 次翻译，每次均断言与基线逐 token 一致。它们是同一 39 条语料的重复测试，不是 4,992 条不同语料。
- ASan/UBSan 的 284 个边界用例通过；未启用内存泄漏检测。
- 独立投影初测耗时下降约 24%–29%，不能直接视作服务加速比例。

## 为什么不合入

1. 中英单线程、四路并发吞吐下降 10.82%；中英双线程、四路并发仅 +0.68%。没有一致的服务收益。
2. 两段计时不足以确认小幅差异；英文双线程并发的基线段间波动明显，不能宣传最高的 +21.11% 为稳定收益。
3. 固定 ELF 指纹与地址的实验分派替换不适合发布。正式实现需维护 ORT 源码补丁或稳定自定义算子接入，以及 CPU 能力检测和回退。
4. 自定义算子的独立调度版本已经出现回退；微基准更快不代表接入成本更低。
5. 未做 HTTP 端到端、多硬件、多语言或长时间独立复测；样本一致不是所有输入的数值等价证明。

## 已排除的错误归因

- 不能将 Loop 捕获的权重视作未预打包：此前对照已证实预打包正常。
- 排除带逐次共享原子计数器的实验数字，它会争用缓存行，干扰并发。最终仅每线程首次命中计数。
- PC 采样不是 precise-IP；不能将落在某条指令上的样本数直接解释为该指令的独占周期。
- 不再重复无稳定收益的 DQL 去重、RNN 合并、TopK 去排序、bias 融合及 transB 小改；ORT 1.30 的 LUT 路径不接受当前 INT4。

## 原始实验与重启条件

本地 `.tmp/projection-kernel/` 保留采样、真实向量、源码、原始计时与验证脚本；这些大体积临时制品未上传，本记录和 JSON 是持久化结论，不是完整可移植复现包。

只有出现稳定的 ORT 源码级接入、其它指令集/运行库改进，或限定负载下独立复测证明净收益，才重启本方案。不得用地址替换作为生产接入。

## 后续组批初筛结果

已用本地 ORT CPU 单线程、固定 CPU 4，测试两个方向各 128 个真实 hidden、batch 1/2/4/8：

- batch=1 的全部 logits 与既有参考逐位一致。
- batch>1 的 logits 不再逐位一致，最大绝对误差约 1.29e-5；但样本中加偏置后的有序 Top9 和候选集合均保持一致。
- 每种配置做四段约 500ms 的独立投影计时。各 batch 按固定顺序测试，耗时波动明显，未做随机化/交替对照，不能将观察到的摊销差异宣传为加速比例。
- 原始指标见 `projection-batch-feasibility.json`。本地脚本在 `.tmp/projection-batch/bench.mjs`。

下一步验证门槛：保持一致的预热、CPU 负载和输入数量，做 batch1 与候选 batch 的多轮交替对照；扩大近似并列 Top9 和边界输入检查。通过后再考虑分离编码/解码并跨请求组批，同时验证等待延迟、取消、EOS 和不同长度请求退出。当前未实现这些架构改动，未声称组批保持所有输入的输出。
