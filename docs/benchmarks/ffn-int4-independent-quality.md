# 解码 FFN INT4：独立参考译文评估

结论：本候选不采用。允许输出变化后，以人工参考译文评估，而不是用逐字一致作为门槛。完整开发集的双向速度均下降，质量指标点估计也略降；置信区间跨零，不能断言显著退化，也不能据此声称质量等价。

## 候选与数据

- 从当前快速模式图出发，将四层解码器 FFN 的 W1/W2 从动态 INT8 改为 MatMulNBits INT4，block_size=64、accuracy_level=4；首步和 Loop 共替换 16 个矩阵节点。使用源发布模型的 FP32 权重重新量化，保留原 bias、ReLU、归一化及 lexical 候选生成。只在隔离模型中测试。
- FLORES-200 英语/简中人工平行参考，先取开发集 id % 10 == 0 的 100 条初筛，再用全部 997 条开发集复核。两个方向使用同一对齐数据。归档 SHA256 与已有 provenance 一致，并逐字节核对归档中的 dev 文件，逐条确认评估 JSON 的 source/reference 与原文件对应。
- 不是模型旧输出作为质量参考，没有为本候选训练或调校权重。dev 用于筛选；devtest 未用于此轮候选选择或验收。无法据此保证数据未曾出现在源模型训练中。
- 每组 baseline/candidate/candidate/baseline，CPU4、单线程、同样词表与分词器。逐模型两遍结果一致；到生成上限而无 EOS 时计为失败、按空译文纳入分数。本轮均为零失败。计时是原始模型 run，包含首条冷内存分配，没有 HTTP/排队/分词耗时，也不是充分的并发性能验收。

## 指标与限制

- SacreBLEU 2.5.1，chrF++ 为 char_order=6、word_order=2、beta=2；BLEU 英译中使用 zh tokenizer，中译英使用 13a。完整 signature 在 JSON。chrF++ 以句对为配对单位重采样 1,000 次，固定 seed=20261113；置信区间仅表示该开发集上的抽样不确定性。
- 没有使用指标分差为同义改写直接判错，也没有把统计不显著当作质量非劣。此轮未做人工盲评、语义模型评估、关键金额/否定/实体的全面审计、其他语言或硬件测试，故不是全面质量批准。后续有稳定速度收益的候选才进入这些更完整的验收。
- 生产代码、默认精度、版本与包未改。模型、逐条输出、脚本保留在 `.tmp/ffn-q4/`；提交仅保留聚合指标、原始计时、校验和与 provenance，不上传 FLORES 原文或模型权重。
