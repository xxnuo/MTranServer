# CPU 性能对比：普通、Fast 与 LinguaSpark

> 已更新：参见 [2026-11-17 复测（v5.4.3）](cpu-comparison-2026-11-17.md)；本文保留 v5.4.2 历史记录。

2026-11-16 实测（替代 [2026-11-14 基线记录](cpu-comparison-2026-11-14.md)）。接入原生 SSRU 解码、两阶段 INT8 候选表与服务热路径优化后，Fast 在短句、段落、长文单请求延迟及并发吞吐、P95 延迟上全面领先普通模式与 LinguaSpark；LinguaSpark 仍保持更低的内存占用与更短的冷启动就绪时间。普通模式优先保证翻译准确性；本轮 27 条基准语料的三方译文与 2026-11-14 完全一致（0 差异），Fast 相比普通模式仍可能增加误译。

结构化数据见 [cpu-comparison-2026-11-16.json](cpu-comparison-2026-11-16.json)。

## 测试条件

- Ryzen 9 9950X，共享 Linux 主机；三方逐个运行，均限制 4 CPU 配额、3 GiB 内存、不使用交换空间，低调度优先级（与 2026-11-14 完全一致）。
- 使用相同 Mozilla 英中、中英模型和语料；关闭翻译缓存，经预转换与预热后轮换顺序测试三轮，共 5193 次正式 CPU HTTP 请求，重复译文一致性检查及跨版本译文核对全部通过。
- MTranServer 5.4.2（提交 `42269eb`），ONNX Runtime 1.30.0，容器启用 `tcmalloc`；普通模式使用 `native-async`（4 线程），Fast 使用 `native-ssru`（单算子线程，4 并发槽位）；LinguaSpark server 固定版本 `edd16a674b1484490a4a29d588dab9c1a191e6c3`，引擎固定版本 `269605c`，4 个 worker。
- 数值为三轮各自指标的中位数；延迟取每轮平均值，P95 取每轮最近秩百分位数。长文英译中 3244 字符，中译英 1516 字符，均为 32 句换行分隔。
- CPU 配额已逐例核对；rootless 环境未委派 cpuset，不能将配额理解为独占四个物理核心。本记录仅包含 CPU 数据。

| 中→英长文（32 句） | 132.40 | **38.45** (-47%) | 218.10 |

## 内存与首次使用

| 指标 | 普通模式 | Fast (5.4.2) | LinguaSpark |
| --- | ---: | ---: | ---: |
| 双模型热态 RSS（MiB） | 533.7 | 651.0 | **313.0** |
| 测试期间峰值 RSS（MiB） | 721.0 | 821.6 | **313.0** |
| 启动至就绪（含预热，ms） | 4377.4 | 1681.6 | **281.0** |
| 首次英→中请求（ms） | 9.2 | 6.7 | **5.5** |
| 首次中→英请求（ms） | 7.6 | **3.6** | 5.3 |

5.4.0 起 MTranServer 在监听端口前自动预热本地已转换模型，因此启动至就绪时间包含了双方向模型加载与校准（Fast 合计约 1.68 s，低于 5.1.3 冷加载首请求的 4.65 s 总和），就绪后首次请求不再承担 2 s 级冷启动开销。若目录内仅有原始 Mozilla 模型文件、尚未生成 ONNX 缓存，首次离线转换耗时另计（本次预转换阶段实测：普通模式首请求英→中 3271.7 ms、中→英 3989.3 ms；Fast 首请求英→中 2375.5 ms、中→英 2642.9 ms）。内存取服务进程 RSS，不等于整个容器或系统的总占用。

## 结论与范围

- 对照组复现性：LinguaSpark 在本轮的短句 8 并发吞吐（1179.90 / 1347.96 req/s）、长文 4 并发吞吐（8.30 / 11.97 req/s）及 RSS（313.0 MiB）与 2026-11-14 偏差均在 1.4% 以内，宿主环境基线稳定。
- 相比 LinguaSpark：Fast 短句单请求延迟低约 32%–33%，短句 8 并发吞吐高约 **58%–64%**（P95 延迟低约 32%–36%）；段落单请求快约 1.64–1.82 倍；32 句长文单请求快约 **5.67–9.61 倍**，4 并发吞吐高约 **2.39–4.63 倍**。LinguaSpark 的常驻与峰值内存仍约为 Fast 的一半（313 MiB vs 651–822 MiB）。
- 相比普通模式：Fast 短句 8 并发吞吐约为普通模式的 **3.06–4.29 倍**，长文单请求快约 **2.55–3.44 倍**；普通模式因启用 `tcmalloc` 释放策略，双模型热态 RSS 由 648.3 MiB 降至 533.7 MiB。

以上是共享主机受限资源下的中英双向测试，未测整机满载、其它语言或长期稳定性。各引擎重复输出一致不代表三方译文相同，也不代表翻译质量等价。
